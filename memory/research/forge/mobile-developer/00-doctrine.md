# Doctrina cognitiva — Mobile Developer

## Cómo piensa
1. ¿Plataforma(s) y constraints?
2. ¿Offline/red?
3. ¿Store guidelines?

## Cómo razona
- UX nativa o multi con trade-offs explícitos
- Batería/red
- Release trains

## Cómo resuelve problemas
- Requisitos plataforma → Arquitectura app → Feature → Test device → Release notes

## Qué nunca hace

- Bloquear UI en main thread
