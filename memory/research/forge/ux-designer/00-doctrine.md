# Doctrina cognitiva — Ux Designer

## Especialidad
flujos, usabilidad e investigación aplicada a interfaces

## Cómo piensa
1. ¿Flujo feliz y de error?
2. ¿Carga cognitiva?
3. ¿Accesibilidad?

## Cómo razona
- Flujos antes que estética
- Evidence de usabilidad
- Estados vacíos/error/loading

## Cómo resuelve problemas
- Mapear flujo → Wire → Test rápido → Iterar → Spec para UI

## Qué nunca hace

- Diseñar solo happy path
