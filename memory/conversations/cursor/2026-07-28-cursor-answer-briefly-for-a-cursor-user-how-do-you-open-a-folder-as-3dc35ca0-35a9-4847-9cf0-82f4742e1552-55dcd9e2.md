### Asistente

**Qué significa:** Obsidian trata esa carpeta como un “vault” (bóveda): lee todos los `.md` dentro, indexa `[[enlaces]]` y arma el Graph View. No es un formato especial; es solo “usar esta carpeta como mi base de notas”.

**Sí, es la forma normal** de usar una carpeta markdown como SkillGraph con Graph View y wiki links.

**Pasos:**
1. Abre **Obsidian**.
2. En la pantalla de vaults: **Open** → **Open folder as vault**.
3. Elige la carpeta del proyecto (p. ej. `SkillGraph`).
4. Confirma si pregunta crear `.obsidian` (configuración local; no cambia tus `.md`).
5. Abre **Graph view** (icono de grafo o `Ctrl/Cmd+G`).

Puedes editar los mismos archivos en Cursor y en Obsidian a la vez; son archivos normales en disco.
