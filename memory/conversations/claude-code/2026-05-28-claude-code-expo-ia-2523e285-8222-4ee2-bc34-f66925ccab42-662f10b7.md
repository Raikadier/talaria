Los Mapas de Kohonen son algoritmos de aprendizaje **no supervisado**, por lo que sus métricas se dividen en dos grupos: métricas propias del SOM y métricas de clasificación estándar (cuando hay etiquetas disponibles).

## Métricas propias del SOM

### 1. Error de Cuantización (Quantization Error — QE)
Mide qué tan bien el mapa representa los datos. Es el promedio de las distancias entre cada muestra y su neurona ganadora (BMU).

```
QE = (1/N) * Σ ||xᵢ - w_BMU(xᵢ)||
```
- Valor bajo → el mapa representa bien los datos.

### 2. Error Topográfico (Topographic Error — TE)
Mide si el mapa preserva la topología del espacio de entrada. Cuenta cuántas muestras tienen su 1ra y 2da BMU **no adyacentes** en la cuadrícula.

```
TE = (1/N) * Σ t(xᵢ)     donde t(xᵢ) = 1 si BMU1 y BMU2 no son vecinas
```
- Rango: [0, 1] → 0 es perfecto.

---

## Métricas de clasificación (cuando hay etiquetas)

Una vez entrenado el SOM, se **etiquetan las neuronas** con la clase mayoritaria de las muestras que cayeron en ellas. Luego aplican:

### 3. Pureza del Mapa (Purity)
Para cada neurona se toma la clase dominante; la pureza global es el porcentaje de muestras bien clasificadas.

```
Purity = (1/N) * Σ max_k |Cₖ ∩ clusterⱼ|
```

### 4. Entropía por neurona
Mide la mezcla de clases dentro de cada neurona. Neurona "pura" → entropía baja.

```
Hⱼ = -Σ p(c|j) * log₂(p(c|j))
```

### 5. Matriz de Confusión + métricas derivadas
Después de asignar etiqueta a cada neurona:

| Métrica | Fórmula |
|---------|---------|
| **Accuracy** | (VP + VN) / Total |
| **Precisión** | VP / (VP + FP) |
| **Recall (Sensibilidad)** | VP / (VP + FN) |
| **F1-Score** | 2 × (P × R) / (P + R) |

### 6. Índice Davies-Bouldin (DB Index)
Mide la calidad de los clusters formados. Relaciona la dispersión interna con la separación entre clusters.
```
DB = (1/K) * Σ max_{i≠j} [(sᵢ + sⱼ) / d(cᵢ, cⱼ)]
```
- Valor bajo → clusters bien separados y compactos.

### 7. Silhouette Score
Para cada muestra mide qué tan parecida es a su propio cluster vs. el cluster vecino más cercano.
```
s(i) = (b(i) - a(i)) / max(a(i), b(i))
```
- Rango: [-1, 1] → cercano a 1 es ideal.

### Usuario

entonces las metricas de clasificacion propias de las som, son: error de cualtificacion, producto topografico y medida de distorcion?

### Asistente

¡Casi! Esas tres **sí son métricas propias del SOM**, pero hay una precisión importante: existe una diferencia entre **Error Topográfico** y **Producto Topográfico** — no son lo mismo. Aquí el cuadro completo:

---

## Métricas propias del SOM ✅

### 1. Error de Cuantización (QE)
Mide qué tan bien el mapa **representa** los datos.
```
QE = (1/N) · Σ ||xᵢ − w_BMU||
```
> Qué tan cerca está cada muestra de su neurona ganadora.

---

### 2. Medida de Distorsión (Distortion Measure)
Es la función que el SOM **minimiza durante el entrenamiento**. Similar al QE pero pondera las neuronas vecinas con la función de vecindad `h`:
```
D = Σᵢ Σⱼ h(BMU(xᵢ), j) · ||xᵢ − wⱼ||²
```
> Considera no solo la neurona ganadora sino también sus vecinas.

---

### 3. Error Topográfico (TE) ← más común en la práctica
Mide si el mapa **preserva la topología**. Cuenta muestras cuya 1ra y 2da BMU **no son adyacentes** en la cuadrícula:
```
TE = (1/N) · Σ t(xᵢ)      donde t = 1 si BMU1 y BMU2 no son vecinas
```
> Rango [0, 1] → 0 es perfecto.

---

### 4. Producto Topográfico (Topographic Product) ← más complejo
Propuesto por Bauer & Pawelzik (1992). Verifica si los **k vecinos más cercanos** en el espacio de entrada se corresponden con los k vecinos en el mapa:
```
P = (1/N·log K) · Σᵢ Σₖ log[ Q1(k,i) · Q2(k,i) ]
```
- `Q1` = razón de distancias en el **espacio de entrada**
- `Q2` = razón de distancias en el **mapa**
- Valor ideal → **P = 0**
  - P < 0 → mapa demasiado pequeño (subdimensionado)
  - P > 0 → mapa demasiado grande (sobredimensionado)

---

## ¿Cuál es la diferencia entre TE y Producto Topográfico?

| | Error Topográfico | Producto Topográfico |
|--|--|--|
| Complejidad | Simple | Complejo |
| Qué mide | Solo BMU1 vs BMU2 | Todos los k vecinos |
| Resultado | Porcentaje de errores | Valor log (≈ 0 ideal) |
| Uso | Más común en papers recientes | Más completo pero menos usado |

---

## Resumen corregido

Las métricas **propias del SOM** son:

```
✅ Error de Cuantización      → calidad de representación
✅ Medida de Distorsión       → función objetivo del entrenamiento  
✅ Error Topográfico          → preservación de topología (simple)
✅ Producto Topográfico       → preservación de topología (completo)
```

> Para tu exposición, lo más estándar es presentar **QE + Error Topográfico** como el par principal, y mencionar el Producto Topográfico como métrica avanzada. ¿Te lo muestro calculado?
