**Dominio:** [[productivity]]

**Descripción:** Read, back up, deduplicate, and reorganize Chromium/Brave bookmarks by editing the Bookmarks JSON file directly. Use when a user wants to sort, clean, dedupe, rename, or restructure their Brave/Chrome/Edge bookmarks, or export/back them up.

**Cuándo usar:** Chromium-based browsers (Brave, Chrome, Edge) store bookmarks as a JSON file. You can read and rewrite it directly — but the file has a **checksum** the browser validates; write it wrong and the browser marks bookmarks corrupt.
