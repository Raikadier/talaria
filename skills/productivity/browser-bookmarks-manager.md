# browser-bookmarks-manager

**Dominio:** [[productivity]]  
**Fuente(s):**
- `C:\Users\david\AppData\Local\hermes\skills\productivity\browser-bookmarks-manager\SKILL.md`

**Descripción:** Read, back up, deduplicate, and reorganize browser bookmarks for Chromium-based browsers (Brave, Chrome, Edge, Vivaldi, Opera). Parses the JSON `Bookmarks` file, exports to Netscape-HTML (importable anywhere) + exact JSON copy, detects duplicates and untitled entries, and rebuilds a clean folder tree. Use when the user asks to organize/order/tidy/back up/export/find/deduplicate their bookmarks ("ordena mis marcadores", "respalda mis favoritos", "organize my bookmarks").

**Cuándo usar:** Chromium browsers store bookmarks as a **plain JSON file** named `Bookmarks` (no extension) in the profile directory. You can read, analyze, and rewrite it directly — no browser API needed.
