**Descripción:** Turn any research question into a structured, source-cited report using only Claude Code's built-in web tools (WebSearch/WebFetch) — no external API keys, no paid services. Use this skill whenever the user asks to "research X", "write a report on X", "compare A vs B", "what is the state of X", "give me a market overview", "summarize the literature on X", or wants any deliverable that requires gathering, verifying, and citing web sources. Trigger even when the user never says the word "report" — any multi-source investigation that should end in a written, citable summary belongs here.

**Cuándo usar:** Produce a decision-grade research report from live web sources. The output is a Markdown report where **every substantive claim is traceable to a named source**, conflicting evidence is surfaced instead of averaged away, and the reader can tell exactly how fresh and how reliable
