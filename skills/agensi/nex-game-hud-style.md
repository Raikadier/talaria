**Descripción:** Apply a game-HUD aesthetic to any website or web app. Inspired by sci-fi game heads-up displays (Halo, Destiny, Cyberpunk 2077, Helldivers 2): corner brackets framing every panel, animated scanlines on dark backgrounds, neon edge-glow on focus, monospace UI with terminal-green or magenta accents, glitch-on-hover transitions, animated SVG corner markers, and "incoming transmission" reveal animations. Ships as a Tailwind layer + tokens.css + a small set of HUD primitives (HudPanel, HudCorner, HudScanlines, HudGlitch, HudReadout, HudTransmission) so the buyer can drop the look onto any existing site without rebuilding it. Use this skill whenever the user asks for "game HUD", "sci-fi UI", "Cyberpunk look", "Halo aesthetic", "Helldivers vibe", or wants a demo / portfolio / landing page that screams "this is a game studio" without actually being a game.

**Cuándo usar:** A drop-in game-HUD aesthetic for websites. Corner brackets, scanlines, neon glow, glitch transitions, monospace readouts. Built as a Tailwind layer that sits on top of any existing project; not a redesign, an overlay.
