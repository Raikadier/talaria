**Descripción:** Use when the user is in a long or multi-day coding session and wants to keep work coherent across Claude Code's context window and across sessions. Routes session-management work through Claude Code's built-in primitives — TaskCreate, the persistent memory system, CLAUDE.md, Plan mode, ScheduleWakeup — instead of manual handoff documents.

**Cuándo usar:** **Trigger Conditions:** The user mentions the session is getting long, they've been working for hours, they're losing track of decisions, they want help maintaining context across a multi-day effort, or they're about to pause / resume work.
