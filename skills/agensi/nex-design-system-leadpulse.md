**Descripción:** Apply the LeadPulse design system to any new or existing web project (Next.js, Vite + Preact, plain Tailwind). The system is a focused dark-first SaaS aesthetic built around three typefaces (Inter for UI, Instrument Serif for headings, JetBrains Mono for code), two accent colors (mint #4EE8E8 and lavender #B47AFF) on a deep neutral background scale, an 8-point spacing grid, and a small set of components (Button, Input, Card, Badge, NavBar, Toast, Modal). Ships as a Tailwind preset + tokens.css, a 12-component shadcn-style library, and a Storybook-style preview page so the buyer can see every variant in one place. Use this skill whenever the user starts a new SaaS frontend, redesigns an existing one, asks for "the LeadPulse look", needs a focused dark theme that is not generic shadcn-default, or wants the design tokens portable to a new framework.

**Cuándo usar:** A focused dark-first SaaS design system: three typefaces, two accents, one neutral scale, twelve components. Strong personality, fast to implement, portable to any Tailwind project.
