**Descripción:** Diagnoses why a Claude skill did not fire when it should have. Returns the single most likely cause from a fixed list of 7, plus the exact one-line fix and a verification step. Use when the user says 'the skill did not trigger', 'Claude ignored my skill', 'why did [name] not fire', 'skill not loading', 'I have a skill for this but Claude did not use it', or after the user has watched Claude reinvent something a skill already encodes. Output is four labelled blocks: LIKELY CAUSE, EVIDENCE, FIX, VERIFY.

**Cuándo usar:** A skill did not fire. The user is annoyed. You diagnose, give the one-line fix, and stop. Four lines total.
