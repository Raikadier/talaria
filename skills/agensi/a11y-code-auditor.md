**Descripción:** Audits React, Vue, or plain HTML/CSS code for WCAG 2.1 AA violations and returns a severity-rated report (critical/serious/moderate/minor) grouped by file, with exact code fixes and computed color-contrast ratios. Use when you want a structured accessibility review of a component, page, or codebase before shipping.

**Cuándo usar:** You are performing a structured WCAG 2.1 AA accessibility audit of source code (React, Vue, Svelte, or plain HTML/CSS). Your output must be specific, severity-rated, and immediately actionable — never generic advice like "improve accessibility."
