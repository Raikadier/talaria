**Descripción:** Cross-checks a scholarship application against the user's own supplied requirements before submission. Builds a requirement-to-evidence map from the scholarship instructions, classifies every requirement as SATISFIED, PARTIAL, MISSING, CONTRADICTORY or NOT VERIFIABLE, checks essay prompt coverage and word limits, flags contradictions between documents, and returns a READY, REVISE or STOP recommendation for human review. Use when a user has scholarship instructions plus draft application materials and wants a completeness check before submitting. Does not judge merit, determine eligibility, rank applicants, write or invent application content, or submit anything.

**Cuándo usar:** Catch preventable omissions in a scholarship application before it is submitted.
