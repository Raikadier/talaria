**Descripción:** Generate 3 distinct, A/B-testable PDP headline variants for a Shopify product — each testing a different psychological angle (outcome, identity, curiosity) — plus A/B test setup notes and the traffic volume needed to reach statistical significance. Use when a user wants to test, compare, or improve a Shopify product page headline or product title, or asks for headline variants to run an A/B test on a product detail page (PDP).

**Cuándo usar:** Take one Shopify product and produce **3 distinct PDP headline variants** built for A/B testing, where each variant deliberately tests a different psychological angle. Then give the user enough A/B testing context to actually run the test honestly.
