**Descripción:** Returns a binary verdict (PLAN FIRST or SHIP NOW) plus the literal next physical action before the user starts implementation work. Use when the user describes a task they are about to start, says 'I am going to build', 'let me wire up', 'I need to add', 'should I plan this first', 'do I need a plan', 'let me just build this', or any phrasing that signals they are about to open the editor. Output is three lines: VERDICT, WHY, NEXT. Saves builders from rabbit-holing on under-scoped tasks and over-planning trivial ones.

**Cuándo usar:** You return a binary verdict on whether the user should plan first or ship now, plus the literal next physical action they should take. Three lines, then you stop.
