# youtube-playlist-extraction

**Dominio:** [[youtube]]  
**Fuente(s):**
- `C:\Users\david\AppData\Local\hermes\skills\data-science\youtube-playlist-extraction\SKILL.md`

**Descripción:** Extract and analyze YouTube playlists on Windows — including the PRIVATE 'Watch Later' (playlist id WL) — and profile a watchlist by content type, theme, channel, duration, and recency. Documents the Windows DPAPI cookie-decryption blocker and its cookies.txt workaround. Use when the user asks to 'balance/analyze my playlists', 'analyze my watchlist', 'what kind of videos are in my WL', or any YouTube playlist dump/analysis on Windows.

**Cuándo usar:** Pull YouTube playlist metadata locally with `yt-dlp` and turn it into a profile of the user's watchlist (types of videos, themes, channels, duration, how old/unwatched the items are) plus a cross-playlist comparison.
