# youtube-niche-finder

**Dominio:** [[youtube]]  
**Fuente(s):**
- `C:\Users\david\AppData\Local\hermes\skills\youtube-growth\youtube-niche-finder\SKILL.md`

**Descripción:** Encuentra y valida nichos de YouTube prometedores (faceless/automation) usando el método de Steffen (página de inicio + transferencia de nicho + X/Twitter) complementado con herramientas reales (NexLev, 1of10 Outlier Scanner, Viewstats), validación de RPM por país y la métrica "views ≫ suscriptores". Usar cuando el usuario quiere encontrar un nicho para un canal de YouTube, validar si un nicho sirve, o investigar oportunidades subestimadas. Incluye el filtro duro de viabilidad y la advertencia de RPM por geografía del creador (clave para creadores en LatAm/Colombia).

**Cuándo usar:** Skill para encontrar nichos de YouTube con **alta demanda, baja oferta, competencia manejable, RPM viable y formato largo (~30 min)**. Combina el método de Steffen (automatización faceless) con validación de datos reales y el filtro de RPM por país del creador.
