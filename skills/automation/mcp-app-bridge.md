**Descripción:** Build and register an MCP server that lets the Hermes agent drive a desktop app via its local HTTP/JSON-RPC API (e.g. Anki via AnkiConnect, Obsidian) OR a cloud account via OAuth 2.0 (YouTube, Gmail, Drive, Calendar). Covers scaffold, Windows registration gotchas in Hermes, raw-MCP smoke testing, the AnkiConnect-on-modern-Anki pitfall, and the OAuth consent/token flow. Use when the user wants a custom tool (not a native/skill tool) that talks to a GUI app on their machine or to their own cloud account.

**Cuándo usar:** Goal: expose a desktop app's local API as agent-usable `mcp_<name>_*` tools.
