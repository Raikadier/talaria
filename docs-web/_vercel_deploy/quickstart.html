Quickstart

De cero a organismo operativo en unos minutos.

1. Obtener el vault

Clona github.com/Raikadier/talaria-skillgraph o abre tu carpeta SkillGraph local.

2. Instalar la CLI

pip install -e .
python -m skillgraph_cli describe --json

3. Verificar salud

python -m skillgraph_cli verify boot --json
python -m skillgraph_cli doctor --json
python -m skillgraph_cli smoke --json

4. Conectar MCP

Configura servidores skillgraph + obsidian según _META/agent-connect.md y las plantillas en tools/connect/.

5. Sesión tipo SPINE

  1. forge list → elige perfil → forge run … --with-axon
  2. Actúa (escribe al vault, usa tools).
  3. forge check + scorecard.
  4. verify close.
python -m skillgraph_cli mode set strict
python -m skillgraph_cli eval run --json

No subas secretos: .gitignore excluye settings locales y .env.
