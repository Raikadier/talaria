Garantías A–F

De “documentado en Markdown” a “fallible en máquina”. Las seis fases están implementadas en CLI 1.0.

FaseEntregaComandoEstado
ABoot/close + scorecardverify boot|closeHecho
BDiagnóstico + humodoctor, smokeHecho
CPerfiles FORGE operablesforge …Hecho
DBúsqueda de skillsaxon …Hecho
EGold tasks + harnesseval list|runHecho
Fstrict vs draftmode get|setHecho

Evals (E)

Specs en _META/evals/*.json con fixtures (p. ej. research brief). Sirven de regresión cuando cambias perfiles o skills.

Modos (F)

  • strict — gates fallan el proceso; pensado para cierre de sesión y CI.
  • draft — avisos sin bloqueo; exploración y prototipos.

Persistencia: .skillgraph.mode, env SKILLGRAPH_MODE o flag --mode.

python -m skillgraph_cli smoke --json
python -m skillgraph_cli eval list --json
python -m skillgraph_cli mode set strict
