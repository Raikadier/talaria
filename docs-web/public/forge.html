FORGE

FORGE forja perfiles de rol elite: no un system prompt genérico, sino contratos con leyes, skills preferidas, gates y scorecards.

Idea

Un perfil FORGE define quién actúa (rol), qué no puede romper (Leyes I/II), qué skills AXON prioriza y cómo se mide el cierre. Así el mismo vault sirve a research, engineering o producto sin mezclar criterios.

Comandos

python -m skillgraph_cli forge list --json
python -m skillgraph_cli forge show <profile> --json
python -m skillgraph_cli forge run <profile> --with-axon --json
python -m skillgraph_cli forge check <profile> --json

Leyes I / II

  • Ley I — invariantes del rol (lo que siempre debe cumplirse).
  • Ley II — límites y anti-patrones (lo que nunca debe hacerse).

forge check evalúa evidencia contra el perfil; en modo strict los fallos bloquean el cierre.

Ubicación

Perfiles en _META/forge/. Extiende con nuevos YAML/Markdown siguiendo el builder documentado en el vault.
