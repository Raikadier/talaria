CLI & MCP

La API es la cara externa del organismo. Todo comando crítico ofrece --json para que un agente lo parsee sin ambigüedad.

Instalación

cd SkillGraph   # o clon de Talaria-skillgraph
pip install -e .
python -m skillgraph_cli describe --json
