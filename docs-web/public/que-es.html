Qué es Mímir

En la mitología nórdica, Mímir custodia el pozo de la sabiduría y aconseja a los dioses. Aquí, Mímir es la marca comercial de un sistema que hace lo mismo para agentes de IA: un pozo operable, con memoria durable y garantías verificables.

Nombre técnico

SkillGraph Cognitive Operating System (SGCOS) es la capa de ingeniería. No es un chatbot con prompts bonitos: es un sistema operativo cognitivo — estado canónico en un vault Markdown, protocolo de trabajo (SPINE), órganos con responsabilidades claras y una API (CLI + MCP) que cualquier piloto puede descubrir sin folklore.

Dos metáforas (misma verdad)

  • Hacia fuera — super-API: describe --json, servidores MCP skillgraph y obsidian, comandos machine-readable. El agente no “adivina” el vault: lo consulta.
  • Hacia dentro — organismo: Memoria, AXON, FORGE, SPINE, API y Tools. Cada órgano hace una cosa; ninguno es un producto aparte que rivalice con el resto.

Principio de una sola verdad

El vault Markdown es la fuente canónica. Conversaciones, mem0 u otros caches son aceleradores — no la verdad. Si algo importa (decisión, perfil, skill, scorecard), vive en el filesystem versionable.

Qué problema resuelve

  • Agentes que pierden contexto entre sesiones.
  • Skills sueltas sin grafo ni descubrimiento.
  • “Roles elite” que se diluyen en un único system prompt.
  • Promesas de calidad sin verify, smoke ni evals.

Mímir convierte eso en un loop cerrado: boot → perfil FORGE → skills AXON → Act → check → scorecard → close — fallible en máquina.
