Qué es Talaria

En la mitología griega, las Talaria son las sandalias aladas de Hermes: el mensajero las calza y atraviesa mundos. Aquí, Talaria es la marca comercial del traje que amplifica agentes de IA — memoria, skills, roles y gates en un solo arnés.

Nombre técnico

SkillGraph Cognitive Operating System (SGCOS) es la capa de ingeniería. No es un chatbot con prompts bonitos: es un sistema operativo cognitivo — estado canónico en un vault Markdown, protocolo de trabajo (SPINE), órganos con responsabilidades claras y una API (CLI + MCP) que cualquier piloto puede descubrir sin folklore.

Metáfora: armadura / calzado de poder

  • Hacia fuera — super-API: describe --json, MCP skillgraph y obsidian. El agente no adivina el vault: lo consulta.
  • Hacia dentro — organismo / traje: Memoria, AXON, FORGE, SPINE, API y Tools. Cada órgano es una placa del arnés.

Principio de una sola verdad

El vault Markdown es la fuente canónica. Conversaciones y caches son aceleradores — no la verdad.

Qué problema resuelve

  • Agentes que pierden contexto entre sesiones.
  • Skills sueltas sin grafo ni descubrimiento.
  • Roles elite que se diluyen en un único system prompt.
  • Promesas de calidad sin verify, smoke ni evals.

Talaria convierte eso en un loop cerrado: boot → perfil FORGE → skills AXON → Act → check → scorecard → close — fallible en máquina.
