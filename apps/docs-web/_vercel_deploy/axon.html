AXON

AXON es la red de skills: descubrimiento, ranking y emparejamiento con perfiles FORGE. Antes “skill web”; ahora órgano con CLI propia.

Qué indexa

Skills bajo skills/ (por dominio: research, productivity, youtube, software-development, …). Cada skill es Markdown operable; AXON las hace consultables sin recorrer el árbol a mano.

Comandos

python -m skillgraph_cli axon search "research brief" --json
python -m skillgraph_cli axon for-profile <profile> --json
python -m skillgraph_cli axon stats --json

Con FORGE

forge run --with-axon resuelve el set de skills recomendado para el perfil activo. El agente deja de adivinar qué skill abrir.
