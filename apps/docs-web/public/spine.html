SPINE

SPINE es el protocolo nervioso del organismo: siete capas que ordenan cómo un agente piensa, actúa y cierra sin saltarse evidencia.

Por qué existe

Sin protocolo, cada chat inventa su propio “método”. SPINE fija una columna vertebral compartida entre Cursor, Hermes, Claude Code u otros pilotos. IRONMAN queda como alias legacy en docs antiguas; el nombre canónico es SPINE.

Las 7 capas (resumen)

  1. Intent — qué se pide y qué no.
  2. Context — Memoria + restricciones del vault.
  3. Role — perfil FORGE activo (Leyes I/II).
  4. Skills — AXON selecciona capacidades relevantes.
  5. Plan — descomposición ejecutable.
  6. Act — ejecución con tools y escritura al vault.
  7. Verify — gates, scorecard y cierre (verify close).

Relación con las garantías

Las fases A–F no reemplazan SPINE: la hacen fallible. verify boot|close, forge check y eval run son sensores en la columna vertebral.
