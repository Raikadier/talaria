Órganos del sistema

TCOS se modela como un organismo: cada órgano tiene una función vital. Si dos órganos hacen lo mismo, hay un bug de diseño.

ÓrganoFunciónUbicaciónCLI
MemoriaEpisodios, decisiones, contexto de proyectos y conversacionesmemory/vía MCP obsidian / lectura vault
AXONRed de skills interconectadas (el “sistema nervioso” de capacidades)skills/ · _META/axon.mdaxon search|for-profile|stats
FORGEPerfiles de rol con Leyes I/II, gates y scorecards_META/forge/forge list|show|check|run
SPINEProtocolo de 7 capas (antes IRONMAN como alias legacy)_META/spine-framework.mdcontrato de sesión
APISuperficie machine-readable: CLI + MCPtalaria_cli/describe, mcp, …
ToolsIngest y actuación (MarkItDown, Graphify, bootstrap)tools/bootstrap.py

Mapa mental

Un agente entra por la API, carga contexto de Memoria, elige un perfil FORGE, recupera skills vía AXON, ejecuta bajo SPINE y usa Tools cuando necesita ingerir o actuar fuera del vault. Al cerrar, deja evidencia (scorecard / notas) en Memoria.
